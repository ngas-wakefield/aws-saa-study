# Validation System

Watching a lesson is not proof of learning.

For every topic, use the ladder below.

## Level 1 — Recall

Close all notes.

Can you explain the topic from memory?

Examples:
- What problem does this service solve?
- When would you choose it?
- What could you confuse it with?

If you need your notes immediately, the topic is not yet retained.

## Level 2 — Compare

Be able to distinguish similar AWS choices.

Examples:
- S3 vs EBS vs EFS
- ALB vs NLB
- Security Groups vs NACLs
- Multi-AZ vs Read Replicas
- SQS vs SNS vs EventBridge
- Lambda vs Fargate
- CloudFront vs Global Accelerator
- Direct Connect vs VPN
- Savings Plans vs Reserved Instances vs Spot

For each comparison answer:
1. What problem does each solve?
2. When would I choose A?
3. When would I choose B?
4. What wording in an exam question points toward each?

## Level 3 — Apply

Do scenario questions **without notes**.

For every wrong or guessed answer, record:
- what requirement you missed
- why your chosen answer fails
- why the correct option fits better
- the trigger phrase you should notice next time

## Level 4 — Retest

Retest Red/Amber topics **3–7 days later**.

Avoid immediately repeating the exact same question; use a new scenario where possible.

## Confidence

### 🟢 Green
- can explain without notes
- can distinguish it from similar services
- can solve scenario questions
- recent practice is roughly 80%+ on the topic

### 🟡 Amber
- concept mostly makes sense
- you hesitate or confuse a similar service
- recent practice roughly 60–79%

### 🔴 Red
- cannot explain it cleanly
- regularly choose the wrong service
- recent practice below roughly 60%

## Friday validation

At the end of each required week:
- [ ] explain the week's core comparisons from memory
- [ ] draw one architecture without notes
- [ ] do a mixed question set
- [ ] review every wrong and guessed answer
- [ ] assign Green / Amber / Red
- [ ] schedule a revisit for every Red

## Mistake categories

Use one of these:
- **Knowledge gap** — I genuinely did not know the concept
- **Misread requirement** — I knew it but missed what the question asked
- **Service confusion** — I mixed up two plausible AWS services
- **Missed keyword** — e.g. lowest cost, minimal operations, low latency, durable
- **Overthinking** — I rejected the simplest answer without a requirement forcing complexity
- **Time pressure** — I rushed or failed to eliminate distractors

The goal is not only to increase your score; it is to make the reason for each miss visible.
