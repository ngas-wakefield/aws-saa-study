# AWS SAA-C03 Study

Study window: **19 September–31 October 2026**  
Target exam: **first week of November 2026**

This repo is a completion-based study system for the **AWS Certified Solutions Architect – Associate (SAA-C03)**.

## How to use this repo

- **Monday–Friday:** required study units
- **Saturday/Sunday:** optional catch-up, labs, architecture drawing, and review
- Target **75–110 minutes** per weekday; maximum around **2 hours**
- Every study issue has a clear definition of done
- Every topic ends with **validation**, not just watching content
- Completing a session and mastering a topic are separate: you can finish the session and still mark the topic Amber/Red for revisit

## Validation loop

1. **Learn** — AWS Skill Builder / official AWS source
2. **Compress** — tiny notes, comparison, or architecture diagram
3. **Recall** — close notes and explain from memory
4. **Apply** — answer scenario questions
5. **Log** — record mistakes and confidence
6. **Retest** — revisit weak topics 3–7 days later

### Confidence

- 🟢 **Green** — can explain without notes and apply in scenarios; recent practice around 80%+
- 🟡 **Amber** — mostly understand but hesitate or confuse similar services
- 🔴 **Red** — cannot explain cleanly or repeatedly miss scenarios
